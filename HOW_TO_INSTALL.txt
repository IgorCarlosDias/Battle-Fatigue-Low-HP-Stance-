====================================================================
  Battle Fatigue (Low HP Stance) v1.1.0 - How to Install
====================================================================

--------------------------------------------------------------------
  ENGLISH
--------------------------------------------------------------------
WHAT YOU NEED:
- Either Unverum (easiest, 1-click) OR UE4SS (for manual install).

Option 1 — Unverum (Recommended / Easiest)
1. Install Unverum: https://gamebanana.com/tools/18251
   (Unverum can also set up UE4SS for you automatically.)
2. Drag and drop Battle-Fatigue-Low-HP-Stance-v1.1.0.zip into Unverum.
3. Check Battle Fatigue (Low HP Stance) and click Launch Game.

Option 2 — Manual Install (UE4SS)
1. First, install UE4SS (v3.0+):
   https://github.com/UE4SS-RE/RE-UE4SS/releases
   Extract the UE4SS files directly into:
   SparkingZERO\Binaries\Win64\
   (This is the folder with SparkingZERO-Win64-Shipping.exe.
    Extracting UE4SS there creates the "Mods" folder for you.)
2. Open Battle-Fatigue-Low-HP-Stance-v1.1.0.zip, go into "ue4ss\",
   and copy the "BattleFatigue" folder into:
   SparkingZERO\Binaries\Win64\Mods\
3. Final folder check — you MUST have:
   SparkingZERO\Binaries\Win64\Mods\BattleFatigue\enabled.txt
   SparkingZERO\Binaries\Win64\Mods\BattleFatigue\Scripts\main.lua
4. Launch the game (enabled.txt activates the mod automatically).
